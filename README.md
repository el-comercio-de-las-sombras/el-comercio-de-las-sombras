# L'Ombra – El Comercio de las Sombras

Diese Version ist direkt für GitHub Pages vorbereitet.

## Upload

Lade den Inhalt dieses Ordners in dein GitHub-Repository hoch:

- `index.html`
- `.nojekyll`
- `assets/`

## GitHub Pages aktivieren

1. Repository auf GitHub öffnen.
2. **Settings** öffnen.
3. Links **Pages** auswählen.
4. Unter **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. **Save**.

Danach erreichst du die Seite normalerweise unter:

`https://DEIN-GITHUB-NAME.github.io/REPOSITORY-NAME/`

Beispiel:

`https://janconradi.github.io/lombra/`

## Struktur

```text
lombra/
├── index.html
├── .nojekyll
└── assets/
    └── images/
        ├── hero-bg.svg
        └── merchant-bg.svg
```

Die Hintergrundgrafiken liegen lokal im Repository. Die Seite ist daher nicht von externen Bildquellen abhängig.
